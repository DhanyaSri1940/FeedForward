# FeedForward – Bridging the Gap Between Excess and Need

FeedForward is a web-based food donation and redistribution platform that connects donors with beneficiaries to reduce food wastage and ensure surplus food reaches people in need.

## Features
- Donor: Donate surplus food.
- Beneficiary: Access available food donations.
- Admin: Manage users and donations.
- Delivery Agent: Coordinate food deliveries.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP

## Installation
1. Clone the repository.
2. Move the folder into XAMPP's `htdocs` directory.
3. Start Apache and MySQL.
4. Import the database using phpMyAdmin.
5. Open `http://localhost/FeedForward/` in your browser.
